# เว็บไซต์ลอยกระทง ปี ๒๕๖๙ | กับพวกเราชาวสตาร์มันนี่ (Star Money Loy Krathong)

เว็บไซต์ที่ผสมผสาน **สาระความรู้เชิงลึกเกี่ยวกับประเพณีลอยกระทงไทย** เข้ากับ **ระบบลอยกระทงออนไลน์แบบตอบโต้เสมือนจริง (Interactive Real-time)** ภายใต้อัตลักษณ์องค์กร **บริษัท สตาร์ มันนี่ จำกัด (มหาชน)** อย่างลงตัวและสมบูรณ์แบบ ๑๐๐%

---

## สรุปการรวมเว็บไซต์ (Merged Architecture)

เว็บไซต์นี้ได้นำเนื้อหาและฟังก์ชันจากทั้ง 2 เว็บไซต์มารวมกันเป็นเว็บเดียว:

### 🌟 ส่วนที่ ๑: ระบบลอยกระทงออนไลน์แบบตอบโต้ (Star Money Interactive River)
- **ผืนน้ำจำลองแบบเรียลไทม์**: แสดงกระทงลอยตามกระแสน้ำ มีแสงจันทร์และแสงสะท้อนระลอกคลื่นน้ำ
- **ระบบสร้างกระทงอธิษฐาน**: มีกระทงมงคล 4 แบบ พร้อมระบุชื่อ สาขา และแท็กคำอธิษฐานด่วน
- **การ์ดคำทำนายดวงดาวมงคล & บันทึกภาพ PNG**: ดาวน์โหลดภาพการ์ดอวยพรความคมชัดสูงเพื่อแชร์ลงโซเชียลมีเดีย
- **ระบบปล่อยโคมลอย & จุดพลุไฟพร้อมเสียง**: เอฟเฟกต์พลุและเสียงระเบิดสมจริงผ่าน Web Audio API
- **ระบบเสียงดนตรีไทยบรรเลง**: เล่นเพลงรำวงวันลอยกระทงทำนองสังเคราะห์แบบระนาดเอกและฉิ่ง-ฉับ
- **ระบบบันทึกและการซิงค์สด**: คนที่เข้าทีหลังจะเห็นกระทงที่เคยมีคนปล่อยไว้ รองรับ BroadcastChannel และ Server API
- **ระบบความปลอดภัยรีเซ็ต**: ป้องกันการรีเซ็ตข้อมูลด้วยรหัสผ่าน `301069`

### 📖 ส่วนที่ ๒: แหล่งเรียนรู้ประเพณีลอยกระทง ๗ บทเรียน (Educational Knowledge)
- **บทที่ ๑ ลอยกระทงคืออะไร**: สรุปเข้าใจใน 1 นาที (เมื่อไร, ทำเพื่ออะไร, ทำอะไร, คุณค่า)
- **บทที่ ๒ คติความเชื่อและที่มา**: แถบ Interactive สลับดูความเชื่อ 5 ด้าน (พระแม่คงคา, คติพราหมณ์, รอยพระพุทธบาท, พระจุฬามณี, พระอุปคุต)
- **บทที่ ๓ เส้นเวลาประวัติศาสตร์**: ไทม์ไลน์ตั้งแต่ก่อนสมัยสุโขทัย สุโขทัย อยุธยา รัตนโกสินทร์ จนถึงยุคปัจจุบัน
- **บทที่ ๔ นางนพมาศ**: วิเคราะห์เปรียบเทียบเรื่องเล่าตามตำนานกับมุมมองนักวิชาการประวัติศาสตร์
- **บทที่ ๕ ส่วนประกอบของกระทง**: อธิบายความหมายเชิงสัญลักษณ์ของฐานกระทง ใบตอง ดอกไม้ ธูป และเทียน
- **บทที่ ๖ ประเพณีแต่ละภาค**: ยี่เป็งเชียงใหม่, กระทงสายตาก, เผาเทียนเล่นไฟสุโขทัย, เจ้าพระยา, ไหลเรือไฟอีสาน
- **บทที่ ๗ รู้หรือไม่ (Interactive Flip Cards)**: การ์ดพลิก 3D เพื่อค้นหาคำตอบที่น่าสนใจ เช่น ที่มาของคำว่า "เปรียง" หรือทำไมต้องจัดเดือน 12

## ระบบบันทึกกระทงและแสดงผลร่วมกันแบบ Real-time (Shared & Persistent Krathong)

เว็บไซต์รองรับการแสดงผลกระทงของผู้ใช้ทุกคนอย่างสมบูรณ์แบบ:
1. **การใช้งานผ่านเบราว์เซอร์ปกติ / หลายแท็บ / หลายหน้าต่าง**:
   - เชื่อมต่อผ่าน **`BroadcastChannel API`** และ **`Storage Event`** เมื่อมีใครกดปล่อยกระทงในหน้าใดหน้าหนึ่ง กระทงจะลอยขึ้นบนหน้าจอของแท็บอื่นๆ ที่เปิดอยู่ทันที
   - คนที่เปิดหน้าเว็บเข้ามาทีหลัง จะเห็นกระทงทั้งหมดที่เคยมีคนปล่อยไว้ลอยอยู่ในสายน้ำ

2. **การใช้งานร่วมกันหลายเครื่องผ่าน Local Network (แนะนำสำหรับบริษัท/สาขา)**:
   - มีไฟล์ `server.py` เพื่อให้ทุกคนในออฟฟิศ/สาขา หรือผู้ใช้อื่นๆ เชื่อมต่อเข้ามาแล้วเห็นกระทงของกันและกันแบบ Real-time
   - รันคำสั่ง:
     ```bash
     python server.py
     ```
   - คนอื่นๆ ในเครือข่ายสามารถเปิด `http://<IP-เครื่องแม่>:8080` เพื่อร่วมลอยกระทง กระทงของทุกคนจะถูกบันทึกลงในไฟล์ `krathongs.json` และแสดงผลให้ทุกคนที่เข้าเว็บได้เห็นพร้อมกันทันที

3. **ระบบรีเซ็ตกระทงพร้อมระบบป้องกันด้วยรหัสผ่าน (Security Reset PIN)**:
   - มีปุ่ม "รีเซ็ตเป็น 0" ที่มุมขวาล่างของหน้าจอ
   - ระบบจะบังคับให้ใส่ **รหัสผ่าน 6 หลัก คือ `301069`** ก่อนเท่านั้น ถึงจะทำการล้างข้อมูลกระทงได้ เพื่อป้องกันการกดพลาดหรือลบข้อมูลโดยไม่ได้ตั้งใจ

## ฟีเจอร์เด่นของเว็บไซต์ (Key Features)

1. **สายน้ำและท้องฟ้าจำลองแบบเรียลไทม์ (Interactive River & Starry Sky)**:
   - จำลองผิวน้ำสะท้อนแสงจันทร์และดวงดาวตามอัตลักษณ์แบรนด์สตาร์มันนี่ (น้ำเงิน-ทอง-ฟ้า)
   - กระทงลอยผ่านสายน้ำอย่างต่อเนื่อง พร้อมแสงเทียนกะพริบและระลอกน้ำ
   - คลิกที่ผิวน้ำเพื่อสร้างระลอกคลื่น หรือคลิกที่กระทงเพื่ออ่านคำอธิษฐานของเพื่อนๆ

2. **ระบบสร้างกระทงอธิษฐาน (Custom Krathong Maker)**:
   - เลือกดีไซน์กระทงมงคล 4 แบบ: บัวทองมั่งคั่ง, ดวงดาวสตาร์, ใบตองรักษ์โลก, เศรษฐีนำโชค
   - กรอกชื่อผู้ส่งและสาขา/แผนก
   - แท็กคำอธิษฐานด่วน (การเงินมั่งคั่ง, ยอดขายปัง, สุขภาพแข็งแรง, ชีวิตสดใส)

3. **การ์ดคำทำนายดวงดาวมงคล & บันทึกภาพ (Fortune Card & Image Export)**:
   - เมื่อลอยกระทงเสร็จ จะได้รับการ์ดคำทำนายดวงการเงิน/โชคลาภประจำวัน
   - มีปุ่ม **"บันทึกภาพการ์ด"** ส่งออกเป็นไฟล์รูปภาพ PNG สำหรับแชร์ลง Facebook / LINE
   - ปุ่มแชร์ลิงก์แคมเปญ

4. **ระบบปล่อยโคมลอย (Floating Sky Lanterns)**:
   - ผู้ใช้สามารถพิมพ์คำขอพรและกดปล่อยโคมลอยลอยขึ้นสู่ท้องฟ้าได้แบบเรียลไทม์

5. **กระดานรวมคำอวยพร (Wishes Wall & Like System)**:
   - คลังคำอธิษฐานทั้งหมด พร้อมช่องค้นหาตามชื่อหรือสาขา
   - ระบบกดส่งกำลังใจ / อนุโมทนาบุญ (❤️ Like) ให้กับกระทงของเพื่อนๆ

6. **ระบบเสียงบรรยากาศ (Web Audio API Synthesizer)**:
   - เสียงธรรมชาติคลื่นน้ำไหลและเสียงกระดิ่งเฉลิมฉลอง สร้างผ่าน Web Audio API โดยไม่ต้องพึ่งพาไฟล์เสียงภายนอก

6. **ระบบจัดเก็บข้อมูลและการเริ่มนับ (Persistence & Zero Start)**:
   - เริ่มต้นจำนวนกระทงที่ **0 ใบ** สำหรับเปิดแคมเปญใหม่
   - บันทึกกระทงที่ผู้ใช้สร้างไว้บน LocalStorage ของเบราว์เซอร์อัตโนมัติ
   - มีปุ่ม "รีเซ็ตเป็น 0" ที่มุมขวาล่างของหน้าเว็บ เพื่อความสะดวกในการทดสอบระบบ

## วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์ได้ทันที
เปิดไฟล์ `index.html` ด้วย Google Chrome, Microsoft Edge, Safari หรือเบราว์เซอร์ใดก็ได้

### วิธีที่ 2: รันผ่าน Local Server (แนะนำ)
เปิด PowerShell หรือ Command Prompt ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
python -m http.server 8080
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:8080`
